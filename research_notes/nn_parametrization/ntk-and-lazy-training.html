NNGP, NTK, and lazy training: what exactly freezes?

From random functions to training kernels: why some wide networks follow their linearization, how parametrization selects the limit, and where feature learning enters.

A wide network can change its predictions substantially while barely changing the features from which those predictions are built. The useful question is what remains fixed during learning. This note separates three objects that are often called “the kernel”: the covariance of a random network, the tangent kernel of a trainable network, and the fixed kernel obtained when training stays close to a linearization.

The derivations use scalar outputs, a fixed finite dataset, and gradient flow unless stated otherwise. They provide the kernel side of the comparison in the TP IV–V note. The companion mean-field note develops a different width limit in which features keep moving.

1. Three objects to keep separate

Fix inputs \(x_1,\ldots,x_m\). Random initialization makes the vector of predictions \(\mathbf f_0=(f_{\theta_0}(x_\mu))_{\mu=1}^m\) random. Training then moves this vector through \(\mathbb R^m\).

ObjectDefinition or constructionQuestion answered
NNGP kernel\(\Sigma(x,x')=\operatorname{Cov}(f_0(x),f_0(x'))\)How are random initial outputs correlated?
Finite-network NTK\(K_\theta(x,x')=\nabla_\theta f_\theta(x)^\top\nabla_\theta f_\theta(x')\)How does a gradient step at one input affect another?
Frozen tangent model\(f_0(x)+\nabla_\theta f_0(x)^\top(\theta-\theta_0)\)What if the initial parameter sensitivities never change?

The NTK exists for a finite nonlinear network and generally changes during training. An infinite-width theorem can make it deterministic and constant in a particular scaling regime. Those are additional conclusions, not part of its definition. The foundational formulation is Jacot, Gabriel, and Hongler (2018).

2. A random network becomes a Gaussian process

Consider a two-layer network with one hidden layer of width \(n\):

\[ f_n(x)=\frac1{\sqrt n}\sum_{i=1}^n a_i\phi(w_i^\top x), \qquad a_i\sim\mathcal N(0,1),\quad w_i\sim\mathcal N(0,I_d/d). \]

All neurons are independent initially, and \(a_i\) is independent of \(w_i\). The input dimension \(d\) is fixed. Write \(\psi_i(x)=a_i\phi(w_i^\top x)\). Each neuron contributes a random function with mean zero. For a fixed collection of inputs, the ordinary multivariate central limit theorem gives

\[ (f_n(x_1),\ldots,f_n(x_m)) \;\Rightarrow\; \mathcal N(0,\Sigma), \qquad \Sigma_{\mu\nu}=\mathbb E_w[\phi(w^\top x_\mu)\phi(w^\top x_\nu)]. \]

The Gaussian-process statement means this happens consistently for every finite set of inputs. It does not mean that every hidden activation is Gaussian: applying a nonlinear activation to a Gaussian variable usually produces a non-Gaussian variable.

Deep networks repeat the covariance calculation layer by layer. This is the same covariance propagation used in deep information propagation, now interpreted as a prior over functions. See Lee et al., Deep Neural Networks as Gaussian Processes.

3. The function-space training equation is exact

Let \(J_t\) be the \(m\times P\) Jacobian of predictions with respect to the \(P\) trainable coordinates. Its \(\mu\)-th row is \(\nabla_\theta f_{\theta_t}(x_\mu)^\top\). Gradient flow satisfies

\[ \dot\theta_t=-\nabla_\theta\mathcal L =-J_t^\top\nabla_{\mathbf f}\mathcal L. \]

Apply the chain rule once more:

\[ \boxed{\dot{\mathbf f}_t=-K_t\nabla_{\mathbf f}\mathcal L, \qquad K_t=J_tJ_t^\top.} \]

No limit or approximation has appeared. The matrix \(K_t\) is positive semidefinite because \(v^\top K_tv=\|J_t^\top v\|^2\geq0\). Therefore

\[ \frac{d\mathcal L}{dt} =-(\nabla_{\mathbf f}\mathcal L)^\top K_t\nabla_{\mathbf f}\mathcal L\leq0. \]

The difficulty is that \(K_t\) depends on the changing network. A compact equation is not yet a closed equation. The kernel regime becomes tractable when that moving matrix can be replaced by a fixed one.

4. The NTK measures shared parameter sensitivities

Suppose the loss consists of a single example \(x\), with derivative \(r\) with respect to its prediction. A small gradient step gives

\[ \Delta f(x')=-\eta\,r\,K_\theta(x',x)+O(\eta^2). \]

Two inputs interact strongly when changing the same parameter coordinates changes their outputs in similar ways. This is a different notion of similarity from correlation between random initial outputs.

In the two-layer model, the derivatives are

\[ \partial_{a_i}f_n(x)=\frac{\phi(w_i^\top x)}{\sqrt n}, \qquad \nabla_{w_i}f_n(x)=\frac{a_i\phi'(w_i^\top x)x}{\sqrt n}. \]

Consequently, training both layers produces

\[ K_n(x,x')=\frac1n\sum_i\left[ \phi(w_i^\top x)\phi(w_i^\top x') +a_i^2\phi'(w_i^\top x)\phi'(w_i^\top x')\,x^\top x'\right]. \]

The first term comes from adjusting output coefficients; the second comes from adjusting hidden weights. The tangent model contains both sets of initial derivative features, even though those derivative features are held fixed.

5. Frozen hidden weights are a useful special case

If only the \(a_i\) are trained, the model is already exactly linear in its trainable parameters. Its kernel is

\[ K_n^{\mathrm{readout}}(x,x') =\frac1n\sum_i\phi(w_i^\top x)\phi(w_i^\top x'). \]

This kernel is fixed at every width. At initialization and then as \(n\to\infty\), it converges to the same expression as \(\Sigma\) above. That coincidence uses this particular readout variance, feature normalization, and set of trained parameters.

Useful distinction. Training only the last layer is a random-feature model. Linearizing a network that trains every layer is a tangent-feature model. They generally have different feature spaces and different kernels.

Thus “the features freeze” need not mean “the limiting model is equivalent to training only the last layer.” The derivatives with respect to hidden parameters can still contribute to a frozen tangent kernel.

6. Linearization freezes a map from parameters to functions

Expand around the actual initialization:

\[ f_\theta(x)=f_0(x)+J_0(x)(\theta-\theta_0)+R_\theta(x). \]

The linearized model discards \(R_\theta\). It is linear in the parameter displacement, but it can remain highly nonlinear in the input \(x\). For example, \(J_0(x)\) may contain nonlinear gates and products of many randomly initialized layers.

Its Jacobian is always \(J_0\), so its training kernel is always \(K_0\). Lazy training means that the nonlinear network follows this fixed linearization closely over the training interval of interest. Lee et al. (2019) develop this description for wide networks.

There are two different checks: evaluate the Taylor approximation at the nonlinear network's current parameters, and independently train the linearized model from the same initialization. The first checks a local approximation of a function; the second checks an entire training trajectory. A small discrepancy in one is not automatically a bound on the other.

7. A fixed kernel solves squared-loss training

Use \(\mathcal L=\frac12\|\mathbf f-\mathbf y\|^2\), with no division by dataset size. Let \(\mathbf r_t=\mathbf f_t-\mathbf y\). If \(K_t=K_0\), then

\[ \dot{\mathbf r}_t=-K_0\mathbf r_t, \qquad \boxed{\mathbf r_t=e^{-tK_0}\mathbf r_0.} \]

If \(K_0v_j=\lambda_jv_j\), the residual component along \(v_j\) decays as \(e^{-\lambda_jt}\). Large-eigenvalue directions are learned quickly; small-eigenvalue directions take longer. A zero-eigenvalue residual component is untouched.

For gradient descent on the fixed linearized model,

\[ \mathbf r_{k+1}=(I-\eta K_0)\mathbf r_k. \]

Positive-eigenvalue modes contract when \(0<\eta<2/\lambda_{\max}(K_0)\). With the averaged loss \(\|\mathbf r\|^2/(2m)\), replace \(K_0\) by \(K_0/m\), or rescale the learning rate and time. This convention matters when comparing formulas across papers.

8. A two-example calculation

Take

\[ K_0=\begin{pmatrix}2&1\\1&2\end{pmatrix}. \]

The common mode \((1,1)\) has eigenvalue \(3\), while the difference mode \((1,-1)\) has eigenvalue \(1\). Starting from zero predictions, a target \((1,1)\) gives

\[ \mathbf f_t=(1-e^{-3t})(1,1), \]

whereas a target \((1,-1)\) gives

\[ \mathbf f_t=(1-e^{-t})(1,-1). \]

The network starts with the same kernel in both cases, but the second task takes three times as long to reduce its residual by a fixed factor. Kernel eigenvalues acquire meaning only together with the target's alignment with their eigenvectors.

This also explains a form of early-stopping bias: fast modes are fitted before slow ones. It does not establish that fast modes are always the useful modes of a real task.

9. Training interpolation does not determine generalization

Let \(k_0(x,X)\) be the row vector of tangent kernels between a test point and the training inputs. In the frozen model, if \(K_0\) is invertible, integrating its test-point dynamics gives

\[ f_t(x)=f_0(x)+k_0(x,X)K_0^{-1} (I-e^{-tK_0})(\mathbf y-\mathbf f_0). \]

At long times, the training values interpolate, while the extension away from the data depends on \(k_0(x,X)\), the training kernel, and the initial function. A singular \(K_0\) requires the corresponding pseudoinverse and leaves inaccessible residual modes unfitted.

A well-conditioned training kernel can make interpolation easy without making this extension accurate. Optimization and generalization are separate questions.

NNGP Bayesian regression and NTK gradient-flow regression need not agree: one conditions a Gaussian prior with covariance \(\Sigma\); the other evolves a random initial function using \(K\). Even when both yield Gaussian distributions over predictions in an appropriate limit, their covariance structures and inference rules must be compared explicitly.

10. Why this two-layer scaling becomes lazy

Return to \(f_n=n^{-1/2}\sum_i a_i\phi(w_i^\top x)\). Assume bounded inputs, a fixed number of examples, controlled residuals, and a smooth activation with bounded derivatives on the relevant trajectory. For a typical neuron, the formulas in §4 give

\[ \dot a_i=O(n^{-1/2}),\qquad \dot w_i=O(n^{-1/2}). \]

Over a fixed time interval, each hidden feature changes by \(O(n^{-1/2})\). Yet the output can change by order one: the sum of the training-aligned first-order responses contains \(n\) terms of scale \(1/n\).

The initial kernel is an empirical average, so it approaches a deterministic expectation. If its summands change only slightly along a controlled trajectory, the kernel remains close to its initial value. This is the power-counting intuition behind the limit, not a substitute for the estimates needed to control the whole training path.

Limit order. Width goes to infinity at fixed architecture depth, dataset, and training horizon here. Training for a width-dependent time or scaling depth simultaneously asks a different question. Vanishing coordinate movement also does not mean the Euclidean norm of the full parameter displacement vanishes.

11. The deep NTK adds sensitivity from every layer

For a standard fully connected tangent parametrization, write each affine map using trainable order-one Gaussian coordinates with forward factors \(\sigma_w/\sqrt{n_{\ell-1}}\) and \(\sigma_b\) on weights and biases. Let \(\Sigma^\ell\) denote the preactivation covariance. At initialization,

\[ \Sigma^{\ell+1}(x,x') =\sigma_w^2\mathbb E[\phi(U)\phi(V)]+\sigma_b^2, \]

where \((U,V)\) has covariance determined by \(\Sigma^\ell\). Define \(\dot\Sigma^{\ell+1}=\sigma_w^2\mathbb E[\phi'(U)\phi'(V)]\). The limiting tangent kernel obeys

\[ \Theta^{\ell+1} =\Sigma^{\ell+1}+\dot\Sigma^{\ell+1}\Theta^\ell, \qquad \Theta^1=\Sigma^1. \]

Products here are pointwise in the input pair. The new \(\Sigma\) term is sensitivity to the newly added layer's parameters. The other term propagates sensitivity to all earlier parameters through the new layer. The recursion thus sums learning pathways through the network. Its precise form depends on the parametrization and which parameters are trained.

The connection with DIP is immediate: the derivative-correlation factor also governs propagation of sensitivities. TP II explains when the independence heuristics used in such backward calculations are justified, including architectures with reused weights.

12. The training kernel depends on parameter coordinates

Suppose \(W=su\), with \(s>0\) fixed. The forward function can be identical whether \(W\) or \(u\) is stored, but SGD with the same numerical learning rate produces different dynamics:

\[ \nabla_u\mathcal L=s\nabla_W\mathcal L, \qquad \Delta W=-\eta s^2\nabla_W\mathcal L. \]

More generally, for a symmetric positive semidefinite learning-rate or preconditioning matrix \(M_t\),

\[ \dot\theta=-M_tJ_t^\top\nabla_{\mathbf f}\mathcal L, \qquad K_t^{\mathrm{eff}}=J_tM_tJ_t^\top. \]

The effective training kernel is therefore determined by the forward map and the optimizer geometry. A raw \(JJ^\top\) comparison can be misleading when two implementations use different stored coordinates or per-layer rates.

This formula describes a preconditioned gradient flow. Momentum and Adam have additional evolving state; they are not automatically captured by choosing one fixed \(M\). The same-coordinate SGD equivalence is developed further in the spectral note.

13. A model can become lazy without becoming wider

Take any smooth model \(g_\theta\) and form a centered, amplified model

\[ F_{\alpha,\theta}(x)=\alpha[g_\theta(x)-g_{\theta_0}(x)]. \]

The subtracted function is fixed. Use a learning rate proportional to \(\alpha^{-2}\), so function-space learning does not simply accelerate with \(\alpha\). Then \(\nabla_\theta F=\alpha\nabla_\theta g\), and the resulting parameter velocity is of scale \(1/\alpha\) when residuals are controlled.

For a displacement \(\Delta\theta=O(1/\alpha)\), the amplified linear term is \(O(1)\), while the amplified quadratic remainder is

\[ \alpha\,O(\|\Delta\theta\|^2)=O(1/\alpha). \]

A growing output multiplier can therefore make the model increasingly well described by its tangent map. Centering keeps the initial residual bounded as \(\alpha\) grows. This illustrates the scaling viewpoint of Chizat, Oyallon, and Bach (2019).

The argument requires a nondegenerate tangent response and regularity along the path. If the initial derivative is zero in a direction needed for the task, amplifying a zero derivative does not create that missing direction.

14. Change the scaling, change the limit

Now use \(f_n=n^{-1}\sum_i a_i\phi(w_i^\top x)\) and multiply the learning rate of the stored \(a_i,w_i\) by \(n\). The derivatives carry \(1/n\), which the learning rate cancels. Individual neurons can move by order one in order-one training time.

ConventionOutput factorStored-coordinate SGD rateTypical neuron movement
Tangent scaling\(n^{-1/2}\)\(\eta\)\(O(n^{-1/2})\)
Mean-field scaling\(n^{-1}\)\(\eta n\)\(O(1)\)

Both rows assume order-one stored neuron parameters, fixed input dimension, and a fixed training horizon. With independent centered readout weights, initial outputs are order one in the first row and order \(n^{-1/2}\) in the second. The initial functions therefore differ as well as the training dynamics.

The mean-field note translates the second row into effective readout coordinates and recovers the two-layer μP rule. A unique “infinite neural network” does not exist independently of these choices.

15. What would actually demonstrate laziness?

On a fixed diagnostic set, compare three quantities:

\[ D_K(t)=\frac{\|K_t^{\mathrm{eff}}-K_0^{\mathrm{eff}}\|_F} {\|K_0^{\mathrm{eff}}\|_F},\qquad D_h(t)=\frac{\|H_t-H_0\|_F}{\|H_0\|_F}, \] \[ R(t)= \frac{\|\mathbf f_t-\mathbf f_0-J_0(\theta_t-\theta_0)\|_2} {\|\mathbf f_t-\mathbf f_0\|_2}. \]

Evaluate ratios only when their denominators are nonzero; in numerical code report the absolute errors too. \(H_t\) stacks a chosen layer's hidden features on the diagnostic inputs. Also train the frozen tangent model independently and compare its predictions with the network's predictions.

Small hidden movement, small kernel drift, and a small Taylor remainder are related diagnostics, but not equivalent definitions. A kernel can stay almost fixed on the training set while changing elsewhere. Features can rotate without changing their Gram matrix. A small Frobenius change can also hide a consequential change in a small-eigenvalue direction.

16. A small experiment to reproduce the distinction

  1. Fix 32 inputs on the unit circle in \(\mathbb R^2\), with targets \(y(x)=\tanh(3x_1)\). Use a two-layer tanh network and train both layers.
  2. For widths 64, 256, and 1024, implement both rows of the table in §14. Keep each convention's base rate fixed across width. Check that halving the base rate does not qualitatively change the observations.
  3. For each initialized model, construct its own frozen tangent model. Use the same squared loss and stored-coordinate learning rates for that pair. Initialize tangent displacements at zero.
  4. At a fixed number of steps, record training loss, held-out loss on a denser circle, hidden-feature displacement, effective-kernel drift, and nonlinear-versus-tangent prediction error. Repeat with several seeds.

The theoretical expectation is that increasing width improves agreement with the tangent model in the first convention, under a sufficiently controlled training regime. In the second, width alone does not force the discrepancy to disappear. This is an experiment specification, not a report of measured curves; neither limit promises that this particular target will favor feature learning.

Keep the diagnostic inputs, training horizon, and loss reduction fixed. A comparison that changes all three along with width cannot isolate the role of parametrization.

17. How this connects to the existing notes

DIP supplies initial covariance and sensitivity recursions. The NTK asks how all trainable sensitivities combine to move predictions. TP IV then distinguishes scalings whose width limits preserve feature learning from those with kernel-like dynamics.

CompleteP raises a related but different linearization question: a deep network can move features while a multi-operation block becomes increasingly linear in its own parameter changes. Global laziness around the network's original initialization and loss of nonlinear interactions inside each deep block should therefore be checked separately.

What to remember. The exact tangent kernel is a description of training at any width. The frozen-kernel approximation is a particular learning regime. Parametrization decides whether making a network larger drives it toward that regime.

18. Five equations to remember

\[\boxed{\Sigma(x,x')=\operatorname{Cov}(f_0(x),f_0(x'))}\] \[\boxed{K_t=J_tJ_t^\top,\qquad \dot{\mathbf f}_t=-K_t\nabla_{\mathbf f}\mathcal L}\] \[\boxed{f_{\mathrm{lin},\theta}(x)=f_0(x)+J_0(x)(\theta-\theta_0)}\] \[\boxed{\mathbf f_t-\mathbf y=e^{-tK_0}(\mathbf f_0-\mathbf y)\quad\text{for a fixed kernel}}\] \[\boxed{K_t^{\mathrm{eff}}=J_tM_tJ_t^\top}\]

The first is a covariance of random functions. The second is an exact gradient-flow identity. The third freezes sensitivities. The fourth solves the resulting squared-loss dynamics. The fifth makes the role of parameter coordinates and learning rates explicit.
