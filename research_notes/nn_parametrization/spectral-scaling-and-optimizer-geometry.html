Spectral scaling and optimizer geometry: another derivation of μP

Why matrix action matters more than entry size, how stable rank explains maximal-update scaling, and how operator norms connect SGD, Adam, and orthogonalized updates.

A matrix with tiny entries can still change a feature vector by order one. The missing information is how its entries cooperate: independent random weights, a learned outer product, and an orthogonalized update can have very different matrix actions at the same entry scale. Operator norms make that distinction explicit and give another route to maximal-update parametrization.

The main reference is Yang, Simon, and Bernstein, A Spectral Condition for Feature Learning. The worked calculations below use dense MLP layers with RMS-normalized activations, fixed input/output dimensions where specified, and explicit optimizer conventions. They connect the coordinatewise μP derivation to modern matrix-update geometry.

1. Entry size does not determine matrix action

Take a width-\(n\) feature vector \(x\) with \(\|x\|=\Theta(\sqrt n)\). A square random matrix with independent centered entries of scale \(n^{-1/2}\) typically produces order-one output coordinates.

A learned rank-one update can do the same with entries a factor \(\sqrt n\) smaller. For example, let \(u,x\) both have order-one coordinates and set

\[ \Delta W=\frac{\eta}{n}ux^\top. \]

Then

\[ \Delta W x=\eta u\frac{\|x\|^2}{n}=\Theta(\eta)u. \]

Its entries are \(O(\eta/n)\), but its induced feature change has order-\(\eta\) coordinates. The update is correlated with the vector it acts on, so the inner product adds coherently.

This is the two-summation-law argument from TP IV–V. Spectral language expresses the same phenomenon without identifying a matrix with the size of one coordinate.

2. Measure features in RMS units

For a vector \(x\in\mathbb R^p\), use

\[ \|x\|_{\mathrm{RMS}}=\frac{\|x\|_2}{\sqrt p}. \]

An activation with order-one coordinates then has order-one RMS, regardless of width. Let \(W:\mathbb R^p\to\mathbb R^q\). Its induced RMS-to-RMS operator norm is

\[ \begin{aligned} \|W\|_{\mathrm{RMS}\to\mathrm{RMS}} &=\sup_{x\neq0}\frac{\|Wx\|_2/\sqrt q}{\|x\|_2/\sqrt p}\\ &=\sqrt{\frac pq}\,\|W\|_{\mathrm{op}}. \end{aligned} \]

Here \(\|\cdot\|_{\mathrm{op}}\) is the largest singular value. Keeping the normalized operator norm order one suggests

\[ \boxed{\|W\|_{\mathrm{op}}=\Theta\!\left(\sqrt{\frac qp}\right).} \]

The aspect-ratio factor converts Euclidean vector length into per-coordinate feature size. A tall layer can have a growing Euclidean operator norm while still acting at a fixed scale in RMS units.

3. Apply the same units to the update

Holding a layer input fixed, its direct preactivation change is \(\Delta h=\Delta W x\). To allow an order-\(\eta\) feature update at every width, impose

\[ \boxed{\|\Delta W\|_{\mathrm{op}} =\Theta\!\left(\eta\sqrt{\frac qp}\right).} \]

This makes the upper bound

\[ \|\Delta W x\|_{\mathrm{RMS}} \leq\|\Delta W\|_{\mathrm{RMS}\to\mathrm{RMS}}\, \|x\|_{\mathrm{RMS}} =O(\eta) \]

independent of the layer dimensions. The spectral condition asks weights and updates to have compatible action scales; it does not ask their individual entries to have the same scale.

When earlier layers also change, the full preactivation update is

\[ (W+\Delta W)(x+\Delta x)-Wx =W\Delta x+\Delta W x+\Delta W\Delta x. \]

The final term matters for nonlinear parameter interactions. It is small in the base step \(\eta\) when both changes are small, but it need not shrink further merely because width grows. This is the kind of distinction that also matters in CompleteP's block calculation.

4. An operator-norm bound is not a lower bound on learning

Take unit vectors \(u,v\), and a nonzero input \(x\) orthogonal to \(v\). The matrix

\[ \Delta W=\rho\,uv^\top \]

has operator norm \(\rho\), but \(\Delta W x=0\). The update has enough strength somewhere; it is simply pointed away from this input.

A useful alignment diagnostic is

\[ A(\Delta W,x)= \frac{\|\Delta W x\|_2} {\|\Delta W\|_{\mathrm{op}}\|x\|_2}\in[0,1]. \]

A nonvanishing \(A\) turns the spectral upper bound into the intended scale of actual feature movement. Nonlinear gates can introduce an additional attenuation afterward.

The spectral feature-learning analysis establishes this connection in specified training settings and uses additional assumptions when extending its elementary example. It is not a theorem that an arbitrary sequence of matrices with the right norms must learn useful features.

5. A one-example SGD update has perfect alignment

For a dense layer \(h=Wx\), let \(\delta=\nabla_h\mathcal L\). Its gradient is

\[ G=\nabla_W\mathcal L=\delta x^\top, \qquad \Delta W=-\eta_W\delta x^\top. \]

A rank-one matrix has one nonzero singular value, so

\[ \|\Delta W\|_{\mathrm{op}}=\eta_W\|\delta\|\,\|x\|, \qquad \|\Delta W x\|=\eta_W\|\delta\|\,\|x\|^2. \]

Hence \(A(\Delta W,x)=1\), provided both vectors are nonzero. Training itself creates the alignment missing from the arbitrary counterexample.

With a batch of \(B\) examples, the gradient is a sum of \(B\) outer products and has rank at most \(B\). Different terms can reinforce or cancel each other. If batch size or the number of accumulated steps grows with width, fixed-rank intuition needs to be checked again.

Adam's elementwise rescaling and a weight-decay term can also change matrix rank and geometry. The rank-one statement is exact for this plain one-example gradient; it should not be silently transferred to every optimizer update.

6. Stable rank connects entry size to operator norm

For a nonzero matrix, define

\[ \operatorname{srank}(W)= \frac{\|W\|_F^2}{\|W\|_{\mathrm{op}}^2} =\frac{\sum_i s_i^2}{s_{\max}^2}. \]

Stable rank measures how many top-sized singular directions would account for the matrix's total squared magnitude. It can be much smaller than algebraic rank when most singular values are tiny.

For a \(q\times p\) matrix, its RMS entry size is exactly

\[ \operatorname{RMSentries}(W) =\frac{\|W\|_F}{\sqrt{pq}} =\|W\|_{\mathrm{op}} \sqrt{\frac{\operatorname{srank}(W)}{pq}}. \]

For a square matrix with order-one operator norm, a high-stable-rank random initialization has entry size \(n^{-1/2}\); a rank-one update has entry size \(n^{-1}\).

Why small entries can matter. The initialization spreads its action across many singular directions. A learned low-rank update concentrates its action in a few. The latter needs much less total entrywise magnitude to have the same strongest effect on features.

7. Recover the initialization scales

Let \(W_{ij}\) be independent centered Gaussians with standard deviation \(\sigma\). Its operator-norm scale is \(\sigma(\sqrt p+\sqrt q)\). Matching the RMS operator prescription gives

\[ \sigma=\Theta\!\left( \frac{\sqrt{q/p}}{\sqrt p+\sqrt q}\right) =\Theta\!\left(\frac{\sqrt{\min(p,q)}}{p}\right). \]

Only dimension exponents are specified; activation-dependent and aspect-ratio-dependent order-one constants remain to be chosen.

For an MLP with fixed input dimension \(d\), hidden width \(n\), and one output, this yields

\[ W_1:n\times d,\quad \sigma_1=\Theta(d^{-1/2}); \qquad W_2:n\times n,\quad \sigma_2=\Theta(n^{-1/2}); \] \[ W_3:1\times n,\qquad \sigma_3=\Theta(n^{-1}). \]

The small readout now has a direct spectral explanation. A scalar output has Euclidean and RMS size equal, while a hidden input has Euclidean size \(\Theta(\sqrt n)\). A readout norm of \(\Theta(n^{-1/2})\) bounds the output even when the hidden representation aligns with the readout.

8. Why the random initial readout can vanish

Under the previous readout scaling, independent entries of size \(1/n\) acting on an independent order-one feature vector give

\[ \operatorname{Var}(W_3x)=\Theta(1/n). \]

The initial output therefore vanishes in probability under these centered initialization assumptions. The spectral upper bound is order one, but a random initial vector does not saturate it.

After learning, a readout can correlate with the features that generated its update. A one-example readout step is

\[ \Delta W_3=-\frac{\eta}{n}r x^\top,\qquad \Delta f=-\eta r\frac{\|x\|^2}{n}=O(\eta). \]

Thus an initially small random function can acquire an order-one learned response without increasing the readout's width exponent. This is why requiring order-one random output variance at all costs would choose the wrong criterion for this feature-learning scaling.

The mean-field population calculation provides the same example in distributional coordinates.

9. Recover the SGD learning rates

Use a scalar loss with order-one output derivative. In the two-hidden-layer μP MLP at a generic initialization, backpropagated hidden coordinates are of scale \(1/n\). Their Euclidean norms are therefore of scale \(n^{-1/2}\). Hidden activation norms are of scale \(\sqrt n\).

For one example, \(G_\ell=\delta_\ell x_{\ell-1}^\top\). With fixed \(d\), the gradient operator-norm scales are

\[ \|G_1\|_{\mathrm{op}}=\Theta(n^{-1/2}),\qquad \|G_2\|_{\mathrm{op}}=\Theta(1),\qquad \|G_3\|_{\mathrm{op}}=\Theta(\sqrt n). \]

The desired update norms are respectively \(\Theta(\eta\sqrt n)\), \(\Theta(\eta)\), and \(\Theta(\eta/\sqrt n)\), suppressing constants in \(d\). Dividing target update norm by gradient norm gives

\[ \boxed{\eta_{W_1}=\eta n,\qquad \eta_{W_2}=\eta,\qquad \eta_{W_3}=\eta/n.} \]

These are the same rates derived coordinate by coordinate in TP IV–V. They are for the effective weight matrices appearing directly in the forward map, rather than arbitrary stored tensors with additional multipliers.

The first-step derivation assumes nonzero generic gradients. Extending it throughout training requires controlling the feature and gradient scales, not merely reusing an independence assumption from initialization.

This is why the NTK note recommends checking the tangent approximation and actual feature movement. Parameter displacement is meaningful only together with its geometry and its effect on the function.

11. Adam keeps the target update scale but changes the raw rates

At the first step of Adam with zero initial moments and negligible epsilon, bias correction gives a coordinate update proportional to \(-\eta_W\operatorname{sign}(G_{ij})\). For a one-example outer product,

\[ \operatorname{sign}(\delta x^\top) =\operatorname{sign}(\delta)\operatorname{sign}(x)^\top \]

when the entries are nonzero. This sign matrix has operator norm \(\sqrt{pq}\). Requiring its scaled update to have norm \(\eta\sqrt{q/p}\) gives \(\eta_W=\eta/p\), up to width-independent constants.

Consequently, in the same effective-weight convention as §9:

LayerSGD rateAdam rate
Input, fixed \(d\)\(\eta n\)\(\eta\)
Hidden, \(n\times n\)\(\eta\)\(\eta/n\)
Effective readout, \(1\times n\)\(\eta/n\)\(\eta/n\)

Later Adam updates are not generally rank one, and coordinatewise division does not preserve singular vectors. The first-step argument makes the change in width exponents intuitive; it is not a complete derivation of every adaptive training trajectory. Epsilon, moment histories, clipping, and weight decay must be included when checking an implementation.

12. Equivalent forward coordinates need equivalent optimizer coordinates

Let an effective weight be \(W=su\), with \(s>0\). Then \(\nabla_u\mathcal L=s\nabla_W\mathcal L\). For SGD,

\[ \Delta W=s\Delta u=-\eta_u s^2\nabla_W\mathcal L, \qquad \eta_W=s^2\eta_u. \]

For Adam, if the corresponding moment states scale as \(m_u=sm_W\), \(v_u=s^2v_W\), and epsilon is negligible, the gradient normalization cancels one factor of \(s\):

\[ \eta_W=s\eta_u. \]

With non-negligible epsilon, exact matching of this gradient part requires \(\epsilon_u=s\epsilon_W\). A separate weight-decay term must also be transformed so its effective shrinkage agrees.

This is why two μP tables can list different stored initialization variances and learning rates while producing the same effective dynamics. To compare them, first write the forward multiplier and identify which tensor the optimizer actually updates.

The readout convention in the CompleteP table includes an explicit multiplier; its numerical stored-readout rate should not be compared directly with the effective-readout row above.

13. A norm defines what a small optimization step means

Let \(G=\nabla_W\mathcal L\). The first-order loss change is \(\langle G,\Delta W\rangle_F=\operatorname{tr}(G^\top\Delta W)\). A trust-region version of steepest descent solves

\[ \min_{\|\Delta W\|\leq\rho}\langle G,\Delta W\rangle_F. \]

The norm determines which steps are considered equally small. Under a Frobenius-norm budget, the solution is

\[ \Delta W=-\rho\,\frac{G}{\|G\|_F}. \]

Ordinary SGD instead follows from the quadratically penalized problem

\[ \min_{\Delta W}\left\{\langle G,\Delta W\rangle_F +\frac1{2\eta}\|\Delta W\|_F^2\right\}, \qquad \Delta W=-\eta G. \]

A coordinatewise maximum-entry budget gives a sign direction. An operator-norm budget gives a different matrix direction, derived next. These are different geometries of first-order descent, not necessarily approximations to the same Hessian inverse.

Bernstein and Newhouse, Old Optimizer, New Norm develop this perspective and emphasize assigning norms according to each tensor's role.

14. An operator-norm budget produces a polar-factor update

Let the compact SVD of a nonzero gradient be \(G=U_r\Sigma_rV_r^\top\), containing only its positive singular values \(\sigma_1,\ldots,\sigma_r\). Under \(\|\Delta W\|_{\mathrm{op}}\leq\rho\),

\[ \langle G,\Delta W\rangle_F =\sum_{i=1}^r\sigma_i\,u_i^\top\Delta Wv_i \geq-\rho\sum_{i=1}^r\sigma_i. \]

Every term reaches its lower bound for

\[ \boxed{\Delta W=-\rho\,U_rV_r^\top.} \]

This matrix has singular value \(\rho\) in each supported gradient direction. For a rank-deficient gradient, the optimum need not be unique on null subspaces; the compact polar factor is one valid choice.

The minimum first-order loss change is \(-\rho\|G\|_*\), where \(\|G\|_*=\sum_i\sigma_i\) is the nuclear norm. Here the star denotes the nuclear norm; the spectral norm is consistently written \(\|\cdot\|_{\mathrm{op}}\) in this note.

If the budget is stated in RMS operator units, \(\|\Delta W\|_{\mathrm{RMS}\to\mathrm{RMS}}\leq\eta\), then \(\rho=\eta\sqrt{q/p}\). This separates the update's matrix direction from its dimensional scale.

15. Dividing by the largest singular value is a different operation

Take \(G=\operatorname{diag}(3,1)\). Two matrices with operator norm one are

\[ \frac{G}{\|G\|_{\mathrm{op}}} =\operatorname{diag}(1,1/3), \qquad U_rV_r^\top=I. \]

Scalar spectral normalization preserves the ratio of singular values. The polar operation equalizes the nonzero singular values. They satisfy the same largest-singular-value bound but spend that budget differently across directions.

Under a radius-one operator-norm constraint, their first-order decreases are respectively \(10/3\) and \(4\). The polar factor is the steepest choice for this linearized objective and this constraint.

This is not a guarantee of a better finite step: curvature and noise can make aggressive motion in weak gradient directions undesirable. Momentum, regularization, approximate matrix operations, and the learning-rate schedule all affect an actual optimizer.

16. How this connects to Muon

Muon forms a momentum-based update matrix and approximately orthogonalizes it using a small number of Newton–Schulz-style matrix iterations. The polar-factor calculation explains the geometry behind idealized orthogonalized descent. Keller Jordan's original description explains the implementation and its practical choices.

With momentum, the orthogonalized matrix need not be the steepest direction for the instantaneous gradient. Finite-iteration implementations also need not return the exact polar factor. The derivation in §14 should therefore be treated as an explanatory idealization, not a literal specification of every Muon implementation.

Shape-dependent scaling still matters. A full-rank polar factor for a \(q\times p\) matrix has Frobenius norm \(\sqrt{\min(p,q)}\), so a unit RMS-operator update has RMS entry size

\[ \eta\sqrt{\frac qp}\, \frac{\sqrt{\min(p,q)}}{\sqrt{pq}} =\eta\frac{\sqrt{\min(p,q)}}{p}. \]

For a square matrix this is \(\eta/\sqrt n\), whereas a low-rank μP SGD update has entries of scale \(\eta/n\). Both can have order-\(\eta\) operator norm. Their different ranks explain the different entry scales.

Liu et al., Muon is Scalable for LLM Training study update-scale adjustments and weight decay at language-model scale. Their results do not identify every practical Muon scaling convention with the particular RMS-operator prescription derived here.

17. The norm must match the tensor's architectural role

The dense-layer argument assumed the input had order-one RMS. An embedding lookup receives a one-hot vector, whose Euclidean norm is one regardless of vocabulary size. Multiplying by its embedding matrix selects one column.

A relevant operator norm for a matrix \(E:\mathbb R^V\to\mathbb R^n\) is then

\[ \|E\|_{1\to\mathrm{RMS}} =\max_j\frac{\|E_{:j}\|_2}{\sqrt n}. \]

This controls the RMS of every selected embedding column. Treating a one-hot input as a dense RMS-one vector would introduce a spurious vocabulary-size factor.

Biases and normalization gains also have different actions: a bias is added directly, and a gain multiplies coordinates individually. Their updates do not receive the same coherent fan-in sum as a dense matrix.

Attention and residual stacks bring further structure. Projection matrices are only part of a map containing dot products, softmax, token mixing, and depthwise additions. A correct norm for one matrix does not automatically establish stable scaling of the whole architecture.

18. Spectral feature scaling is different from dynamical isometry

The present criterion controls the largest singular value of a weight or update in suitable units. Dynamical isometry concerns the full singular-value distribution of an input-output activation Jacobian.

A rank-one update can be ideal for producing an order-one change on its training example while having zero action on almost every orthogonal direction. There is no contradiction: an update need not preserve every direction to improve a representation.

Conversely, perfectly orthogonal initial weights do not prescribe how learning-rate scales should change with width. A poor optimizer scaling can still freeze features or make updates diverge.

Three separate checks. Examine weight action at initialization, update action during learning, and the full network's sensitivity across depth. None of these matrices can stand in for the other two.

19. A small experiment that distinguishes entries from action

For each width \(n\), sample independent standard Gaussian vectors \(u,x\) and an independent Gaussian matrix \(W\) with entry variance \(1/n\). Form \(A=ux^\top/n\). Then measure

\[ \operatorname{RMSentries}(W),\quad \operatorname{RMSentries}(A),\quad \|W\|_{\mathrm{op}},\quad\|A\|_{\mathrm{op}},\quad \frac{\|Ax\|}{\sqrt n}. \]

The matrix \(A\) has exact operator norm \(\|u\|\|x\|/n\). Its entries shrink like \(1/n\), but its action on \(x\) has order-one RMS. Acting on an independent Gaussian vector \(x'\) instead gives order-\(n^{-1/2}\) RMS, exposing the role of alignment.

For a training diagnostic, use the MLP and effective-coordinate SGD rates in §9. Across widths, record weight and update operator norms in RMS units, stable rank, alignment with the current layer input, and actual feature changes. Hold input dimension, batch size, loss reduction, and the number of steps fixed.

These are proposed checks rather than reported training measurements. They can reveal an incorrect exponent, but stable norms alone do not establish useful feature learning or successful hyperparameter transfer.

20. Five equations to remember

\[\boxed{\|W\|_{\mathrm{RMS}\to\mathrm{RMS}}=\sqrt{p/q}\,\|W\|_{\mathrm{op}}}\] \[\boxed{\|W\|_{\mathrm{op}}=\Theta(\sqrt{q/p}),\quad \|\Delta W\|_{\mathrm{op}}=\Theta(\eta\sqrt{q/p})}\] \[\boxed{\operatorname{RMSentries}(W)=\|W\|_{\mathrm{op}} \sqrt{\operatorname{srank}(W)/(pq)}}\] \[\boxed{\Delta W=-\eta_W\delta x^\top,\quad \|\Delta W x\|=\|\Delta W\|_{\mathrm{op}}\|x\|}\] \[\boxed{\arg\min_{\|\Delta W\|_{\mathrm{op}}\leq\rho} \langle G,\Delta W\rangle_F\ \ni\ -\rho U_rV_r^\top}\]

RMS units explain the aspect-ratio factor. Stable rank explains the difference between initialization and update entry scales. Gradient alignment turns available matrix strength into feature movement. The polar factor shows how a choice of norm can also determine an optimizer's direction.
